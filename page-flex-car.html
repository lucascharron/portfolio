Flex CAR

C’est un site qui nous a permis de maîtriser le flex CSS.

  • Projet de formation

Contexte

Ce projet avait pour but d’apprendre à utiliser flexbox en CSS et à mettre en place le responsive d’un site.

Mon rôle

J’avais pour rôle, dans ce projet, de développeur junior qui devait faire un site pour une entreprise automobile.

Ce que j’ai appris

J’ai appris à maîtriser flexbox en CSS et à voir comment fonctionnent les media queries pour rendre un site responsive.
